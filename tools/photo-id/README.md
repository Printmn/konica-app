# Цээж зураг — вэб хэрэгсэл

Зураг оруулахад нүүрийг өөрөө олж, арын дэвсгэрийг цагаан болгож, баримтын
стандартын дагуу таслаад **300 DPI**-аар хэвлэхэд бэлэн ганц файл гаргана.

Хэмжээ: **3×4**, **3.5×4.5**, **4×6**, **2×3 см**.

---

## Хурдан эхлүүлэх

```bash
cd tools/photo-id
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn server:app --reload --port 8000
```

`http://localhost:8000` нээ.

Эхний удаа арын дэвсгэр авахад `rembg` нь u2net моделийг (~176MB) татна. Дараа
нь офлайн ажиллана.

## Docker

```bash
docker build -t tseej-zurag .
docker run -p 8000:8000 tseej-zurag
```

Модель нь image дотор шигтгэгдсэн тул анхны хэрэглэгч хүлээхгүй.

## Стандарт

ICAO 9303-ын дүрмийг баримталсан (Монголын баримтын зураг үүнийг дагадаг):

- Толгой (оройноос эрүү хүртэл) зургийн өндрийн **70–80%** — бид 75% авдаг.
- Нүдний шугам доод захаас **50–60%** — бид 56% авдаг.
- Нүүр хэвтээ тэнхлэгт голлоно.

Тохируулах бол `geometry.py`-ийн `HEAD_RATIO`, `EYE_FROM_TOP` тогтмолуудыг өөрчил.
Нүүр илрүүлэгчийн хайрцгаас жинхэнэ толгойн өндөр рүү шилжүүлэх коэффициент нь
`BOX_TO_HEAD = 1.45` — Haar cascade-д тохируулсан утга. Хэрэв гаралт байнга
хэт ойр эсвэл хэт хол гарч байвал энэ тоог л хөдөлгө.

## API

```
GET  /api/sizes      → хэмжээ, дэвсгэрийн жагсаалт (нүүр хуудас үүнээс товчоо барина)
POST /api/process    → multipart: photo, size, background, dpi, remove_background
                       ← image/jpeg + X-Head-Share, X-Eye-From-Bottom,
                         X-Background-Removed, X-Pixels толгойнууд
```

Алдааг 400-аар, монгол мессежтэй буцаана (`Нүүр олдсонгүй…`), тул нүүр хуудас
шууд харуулж чадна.

## Хязгаарлалт

- **Нүүр илрүүлэлт** нь OpenCV-ийн Haar cascade. Урдаас, гэрэлтэй авсан зурагт
  сайн; хажуу тийш эргэсэн, сүүдэртэй зурагт алдана. Нарийвчлал хэрэгтэй бол
  `pipeline.detect_face`-ийг MediaPipe Face Mesh-ээр солиход бусад код өөрчлөгдөхгүй.
- **Арын дэвсгэр** авахад буржгар үс, нимгэн шил зэрэг нарийн ирмэг заримдаа
  бүдгэрнэ. Хүнд тохиолдолд «Хэвээр» сонгоод гараар засах нь хурдан.
- **Нүүр олдоогүй** үед зориуд таслахгүй. Буруу таслагдсан зураг хэвлэгдснээс
  дахин авахыг хүссэн нь хямд.

## Дараагийн алхам (хийгээгүй, хэрэгтэй бол)

- Олон зургийг нэг дор боловсруулах (batch).
- 10×15 эсвэл A4 хуудсанд олон ширхэг байрлуулж, таслах шугам зурах.
- Нүдний шугам, толгойн хүрээг зураг дээр давхарлаж харуулах (шалгах зориулалтаар).
- `printmn` апптай холбож, захиалгын дугаараар нь хадгалах.
